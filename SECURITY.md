## Reporting a Vulnerability

We take the security of our open-source tools and interactive sandbox seriously.

If you discover a security vulnerability (such as prompt injection vectors, cross-site scripting vulnerabilities, or exposed secrets), please follow these steps:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Email details of the vulnerability directly to the repository maintainer.
3. Please include:
   - Description of the issue and potential risk.
   - Proof-of-concept code or step-by-step reproduction instructions.
   - Any suggested mitigations or patches.

We will acknowledge receipt within 48 hours and work with you to address and patch the issue promptly.
