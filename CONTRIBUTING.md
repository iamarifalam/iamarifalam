# Contributing to Agentic Routing & AI Sandbox

Thank you for your interest in contributing to this project! We welcome contributions from developers, researchers, open-source maintainers, and educators worldwide.

## 🚀 How to Contribute

### 1. Reporting Bugs
- Open an Issue using the **Bug Report** template.
- Include detailed steps to reproduce, expected behavior, and system environment (Node version, OS, browser).

### 2. Suggesting Enhancements & Features
- Open an Issue using the **Feature Request** template.
- Describe the proposed multi-agent flow, node type, or interface enhancement.

### 3. Pull Requests
1. **Fork** the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/amazing-agent-flow
   ```
2. Make your updates and test locally.
3. Commit with clear, descriptive messages:
   ```bash
   git commit -m "feat: add vector database fallbacks to interactive sandbox"
   ```
4. Push to your fork and submit a Pull Request targeting `main`.

## 🛠️ Code Guidelines
- Maintain clean JavaScript / HTML / CSS code formatting.
- Ensure interactive README mini-game links and visual lab routes function seamlessly.
- Preserve existing documentation and license headers.

## 📜 Code of Conduct
Please review and adhere to our [Code of Conduct](.github/CODE_OF_CONDUCT.md) in all interactions within this project.
